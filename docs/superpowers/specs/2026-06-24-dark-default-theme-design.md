# 默认暗色主题设计

## 目标

首次进入网站且没有已保存主题偏好时，默认使用现有暗色主题。

## 行为契约

- `localStorage` 中存在 `med-utopia-theme=light` 时继续使用浅色。
- `localStorage` 中存在 `med-utopia-theme=dark` 时继续使用暗色。
- 没有合法保存值时固定使用暗色，不再读取系统配色偏好。
- 用户仍可通过现有主题按钮在浅色与暗色间切换；选择继续写入 `localStorage`。
- 不修改现有暗色视觉、设计令牌、组件样式或页面结构。

## 验证

- 单元测试覆盖无偏好默认暗色和已保存浅色优先。
- 全量测试、设计令牌校验和生产构建通过。
- 浏览器清除主题存储后重新进入首页，应呈现 `data-theme="dark"`，主题按钮应显示“切换为浅色主题”。
