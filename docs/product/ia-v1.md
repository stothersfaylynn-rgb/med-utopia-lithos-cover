# 医学理想国 / Med-Utopia 第一版信息架构

- 状态：待确认
- 版本：IA v1
- 日期：2026-06-20
- 范围：首页、避雷案例、学术挑战、专家策展、美学引擎、申请内测
- 产品主轴：避雷案例 + 专家点评 + 学术挑战

## 0. IA 决策

采用“首页分流 + 内容列表/详情下钻 + 可选申请”的 Hub-and-Spoke 架构。

- 采用：三个核心模块都能直接进入，案例与挑战各自拥有稳定列表页和详情页。
- 采用：专家点评作为案例详情、挑战详情和专家策展中的权威内容层，不再新增同权顶级页面。
- 不采用：强制按“案例 -> 点评 -> 挑战 -> 申请”完成的线性漏斗。
- 不采用：把专家点评拆成独立内容门户；这会割裂点评与具体病例、证据和判断依据。
- 不采用：继续用 `/work` 承载五个不可深链接的概念卡片。

## 1. 一句话产品定义

医学理想国是一个面向医学学习者与临床医生的高信号医学知识与判断平台，通过脱敏避雷案例、可追溯专家点评和可参与学术挑战，帮助用户发现、理解并展示高质量医学判断。

## 2. 第一版核心用户循环

```text
进入首页或任一深链接
-> 自由选择避雷案例、专家点评或学术挑战
-> 获得一次明确的医学判断价值
-> 按需进入相关案例、专家点评或挑战继续理解
-> 可选申请内测或参与，留下轻量信号
```

循环成立不依赖申请。只完成一次高价值阅读，也算首访成功。

### 价值与信号

| 层 | 用户动作 | 第一版结果 |
|---|---|---|
| 内容吸引 | 阅读案例或专家点评 | 理解一个决策节点、误判和修正原则 |
| 用户参与 | 查看挑战要求与样例 | 判断自己是否愿意参与 |
| 权威验证 | 从专家策展进入具体点评 | 看见专家观点与案例、证据的对应关系 |
| 可选转化 | 提交内测/参与申请 | 留下身份、方向与联系方式 |

### Level 0 到 Level 4 定义

| 层级 | 本项目含义 | 第一版内容 |
|---|---|---|
| Level 0 | 产品叙事 | 医学知识与判断平台；核心是案例、点评、挑战 |
| Level 1 | 全局可达的主入口 | 首页、避雷案例、学术挑战、专家策展、美学引擎、申请内测 |
| Level 2 | 可独立访问的页面或核心页面区域 | 列表、详情、策展页、Coming Soon 页、申请页 |
| Level 3 | 页面内可深链接的内容章节或状态 | 决策节点、专家点评、样例、筛选结果、提交成功等 |
| Level 4 | 用户可完成的原子交互 | 进入详情、筛选、跳转锚点、查看关联内容、提交申请、返回上级 |

### 路由约束

- 所有 Level 1、Level 2 内容必须拥有稳定 URL，可刷新、可分享、可直接访问。
- `/work` 不再作为正式内容入口；旧地址后续应重定向到 `/#core-entrances`。
- 专家点评没有独立顶级路由。完整点评的标准深链接是 `/cases/:caseSlug#expert-commentary`。
- 筛选条件写入 URL query，刷新或分享后结果不丢失。
- 内容不存在时显示当前页面内的“未找到”状态，并提供“返回案例库”或“返回挑战列表”，不制造死路。

## 6. 用户路径

### 6.1 首页到案例列表

```text
首页
-> 顶部导航“避雷案例”或核心入口“查看避雷案例”
-> /cases
```

主要点击：1 次。

### 6.2 首页到案例详情

标准路径：

```text
首页
-> “避雷案例”
-> 案例卡“查看完整复盘”
-> /cases/:caseSlug
```

主要点击：2 次。

精选直达路径：

```text
首页
-> “阅读本周案例”
-> /cases/acute-aortic-dissection-triage
```

主要点击：1 次。

### 6.3 首页到专家点评

```text
首页
-> “阅读专家点评”
-> /cases/acute-aortic-dissection-triage#expert-commentary
```

点评始终与病例和证据同页，避免脱离上下文的名人背书。

### 6.4 首页到挑战详情

```text
首页
-> “查看学术挑战”
-> 挑战卡“查看挑战详情”
-> /challenges/:challengeSlug
```

主要点击：2 次。首页精选挑战也可 1 次直达。

### 6.5 首页到申请内测

```text
首页
-> “申请内测”
-> /apply?source=home
```

主要点击：1 次；这条路径可见但不强制。

### 6.6 自由进入与跨模块路径

- 案例详情 -> 相关挑战：`/cases/:caseSlug#related` -> `/challenges/:challengeSlug`
- 挑战详情 -> 关联案例：`/challenges/:challengeSlug#related-case` -> `/cases/:caseSlug`
- 专家策展 -> 策展案例：`/curators` -> `/cases?curator=:expertSlug`
- 专家策展 -> 完整点评：`/curators` -> `/cases/:caseSlug#expert-commentary`
- 任一页面 -> 申请内测：全局 CTA -> `/apply?source=:page`

以上互相导向，不设置“完成上一步才能进入下一步”的门槛。

必填字段：

- 身份：医学学生 / 住院医师 / 临床医生 / 专家或资深临床工作者 / 其他医学相关从业者；
- 专科或关注方向；
- 联系方式；
- 希望参与的模块：避雷案例 / 学术挑战 / 专家策展 / 美学引擎；
- 简短参与动机；
- 隐私与联系同意。

系统字段：

- `source`、`type`、`case`、`challenge`、`expert`、`module`；
- 提交时间、提交状态、错误状态、成功状态。

第一版不要求账号，不接收医学文件，不提供站内消息。

### 8.6 枚举与首页配置

- 科室：急诊医学、内科、外科/围术期；
- 风险类型：分诊与鉴别偏差、过度处置、治疗节奏与监测；
- 难度：基础、进阶；
- 挑战类型：临床推理、文献解读、病例复盘、策展任务；
- 挑战状态：开放申请、预告、已结束；
- 首页精选配置：1 个案例 ID、1 条专家点评 ID、1 个挑战 ID、3 位专家 ID；
- 通用状态：默认、筛选无结果、内容未找到、表单校验失败、提交成功。

## 9. 明确延期的功能

以下内容不进入第一版页面、导航、CTA 或 Mock 交互：

- 真实登录、注册、账号与个人中心；
- 支付、退款、订阅和价格体系；
- 站内文件上传；
- 报告/PPT/科研海报的真实美化与交付流程；
- 站内挑战答案提交、附件提交和自动评分；
- 实时聊天、专家咨询、私信和群组；
- 人才市场、人才画像、能力档案与排行榜；
- B2B 招聘、机构合作后台和完整管理后台；
- 专家预约、交易或市场化撮合；
- 医学数据授权、许可与交易流程；
- AI 自动诊断、临床决策建议或面向患者的问诊工具；
- 收藏、关注、评论、点赞、通知和社交信息流；
- 多语言、复杂个性化推荐与站内搜索；
- 独立专家详情页和独立专家点评门户。

“能力沉淀”和“人才画像”只能作为长期结果讨论，不能在第一版导航或页面中暗示已经存在。

## 10. 页面开发优先级

### 前置基础

在页面开发前先固定路由表、Mock 数据关系和全局导航链接；这不是视觉改造，不改变已锁定的首页双图资产。

| 顺序 | 页面/工作 | 优先级 | 原因 | 完成标志 |
|---:|---|---|---|---|
| 0 | 路由、全局导航、内容关系模型 | P0 | 先消除假按钮和不可深链接 | 每个全局入口都有稳定 URL |
| 1 | 避雷案例详情 `/cases/:caseSlug` | P0 | 最集中证明“案例 + 专家点评”的核心价值，并定义内容模型 | 一条案例可完整阅读并进入点评、证据、原则和相关挑战 |
| 2 | 避雷案例列表 `/cases` | P0 | 让首页与导航能进入真实内容 | 可筛选、可聚焦、可打开 3 条案例 |
| 3 | 学术挑战详情 `/challenges/:challengeSlug` | P0 | 证明参与层价值 | 可理解任务、样例、专家提示并可选申请 |
| 4 | 学术挑战列表 `/challenges` | P0 | 建立挑战直接入口 | 可按类型进入 3 条挑战 |
| 5 | 首页入口与精选内容映射 `/` | P0 | 把现有品牌入口接到真实产品路径 | 首页到案例详情最多 2 次主要点击 |
| 6 | 专家策展 `/curators` | P1 | 建立可追溯权威层，不抢占核心主轴 | 3 位专家均能导向具体案例/点评 |
| 7 | 申请内测 `/apply` | P1 | 承接可选转化 | 无需登录即可提交并看到成功状态 |
| 8 | 美学引擎 `/aesthetic-engine` | P2 | 只需准确表达 Coming Soon | 无上传入口，仅可登记内测意向 |

**下一张页面先做：避雷案例详情页 `/cases/acute-aortic-dissection-triage`。**

理由：它同时验证病例结构、专家点评的上下文绑定、证据与原则的层级，以及案例到挑战的跨模块关系；先把这页做实，案例列表与首页预览才有真实内容可导向。任何审美实现仍必须先提供桌面端和移动端预览图并获得确认。
